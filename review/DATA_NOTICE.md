# Derived evidence and source attribution

The current BDG2 operational-pilot publication adds real-data derived observed/predicted interval streams and simulated-fault accounting for one authorized fold/seed and ten buildings. Its [specific source attribution, CC BY-SA notice and transformation record](bdg2_operational_pilot_20260913/DATA_NOTICE.md) govern that new derived-data scope. Oversized stream bytes are supplied as lossless parts; no local raw archive or prepared cache is newly published. The paragraphs below describe the earlier amendment implementation and forecasting-pilot publications.

This review branch publishes ConfoSense code and derived research evidence with the repository owner's explicit authorization of 13 September 2026. It does not publish the local raw, interim or processed source-data directories, virtual environments or external backups.

The amendment-004 descendant adds four-task derived membership/exposure, event-schedule, scale and applicability records, with no real-data operational predictions or fitted models. The new prediction/interval/alert arrays are explicitly synthetic software fixtures, including one tiny actual CQR fit on generated data. Existing source provenance and dataset adapters remain the source records for PLEIA, RICO and BDG2. The local prepared-data caches remain in the external backup directory and are not published. Earlier pilot evidence and rights metadata below are preserved.

The PLEIA temperature truths, model predictions, calibration errors, event-free membership records and diagnostic development predictions are derived from **Antonio Martínez Ibarra, Aurora González-Vidal and Antonio Skarmeta Gómez**, *PLEIAData: consumption, HVAC (Heating, Ventilation & Air Conditioning), temperature, weather and motion sensor data for smart buildings applications*, [Zenodo record 7620136](https://zenodo.org/records/7620136), DOI **10.5281/zenodo.7620136**. The [record API](https://zenodo.org/api/records/7620136) identifies the source license as **[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)**. The retrieved attribution/license metadata is saved in [pleia_rights_metadata.json](pleia_rights_metadata.json).

ConfoSense's transformations include target selection, physical-range masking, causal treatment of locally flagged gaps, feature/sequence construction, temporal splitting, model fitting and derived metric calculation. These are modified/derived artifacts, not an unmodified redistribution of the authors' archive. The source authors do not endorse the project's models, conclusions or implementation. The original dataset license and attribution apply to the source-derived material; this notice does not change the repository software's existing license terms.

The legacy adapter's descriptive citation names different authors; that text is not the authority for this attribution. The evaluated pilot and its provenance remain preserved rather than edited retrospectively. The current source/license notice uses the verified record metadata and the panel plan retains the broader bibliography correction.

Small fitted pilot artifacts (approximately 0.14 MB per LSTM and 0.47 MB per XGBoost model) are included so checkpoints and saved predictions can be checked; no oversized weights are added. The nine unit prediction/calibration files permit metric recomputation without downloading the raw source archive. They do not by themselves reproduce model training: that requires the cited source data, exact evaluated code/configuration, environment and preprocessing.

Historical non-PLEIA outputs already present in the dissertation history are retained as historical summaries, event/membership ledgers and provenance. They are not new raw dataset releases or newly validated experimental claims. See [CURRENT_EVIDENCE.md](CURRENT_EVIDENCE.md) for the current, bounded evidence and explicit local-only inventory.
