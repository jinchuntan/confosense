# BDG2 derived operational evidence

The dataset source is Clayton Miller, Anjukan Kathirgamanathan, Bianca Picchetti, Pandarasamy Arjunan, June Young Park, Zoltan Nagy, Paul Raftery, Brodie W. Hobson, Zixiao Shi and Forrest Meggers (2020), *The Building Data Genome Project 2, energy meter data from the ASHRAE Great Energy Predictor III competition*, Scientific Data 7, 368, [DOI 10.1038/s41597-020-00712-x](https://doi.org/10.1038/s41597-020-00712-x). The [authors' repository](https://github.com/buds-lab/building-data-genome-project-2) is the adapter's source.

Its [LICENSE file](https://github.com/buds-lab/building-data-genome-project-2/blob/master/LICENSE), inspected on 13 September 2026, identifies Attribution-ShareAlike 4.0. The newly published BDG2-derived observation, prediction, membership, synthetic corruption and metric evidence in this review is attributed to that source and shared under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The source license notice applies to those derived data; it does not replace the repository software's license. The legacy adapter's short provenance string says “MIT (repository)”; that string is inconsistent with the inspected source LICENSE and is not the publication's license authority. Evaluated source bytes are preserved.

Changes include the pre-existing ten-building selection and causal preparation, hourly one-step feature construction, the amendment's fixed temporal memberships, fitted quantile forecasts, interval calibration and replay, synthetic event injection, episode matching and derived metric calculations. Injected faults are simulated, not labelled naturally occurring building faults. The source authors do not endorse this implementation or its findings.

Raw source archives, the other buildings, local prepared caches, Python environments and external backups are not newly published. Saved streams contain the monitored derived observations needed to recompute this bounded result. The original forecast pilot and earlier evidence remain historical artifacts with their existing notices.
