# Method specifications and primary references

The frozen [machine-readable specification](../../smart_building_conformal/protocols/matched_intervals005/bdg2_f2_s42_v1/method_specification.json) resolves the actual installed factories and numerical conventions. This task preserves their declared behavior; it does not substitute a newly tuned method for a legacy name.

| Method | Primary reference | Actual owner / implementation |

The three paper records were checked against their primary publication/arXiv pages on14 September2026. Exact installed library source paths/hashes and versions are recorded in [installed_contracts.json](installed_contracts.json); the installed code controls this pinned run rather than potentially newer online documentation.

MAPIE implementation details matter: `TimeSeriesRegressor.fit` fits one full-training predictor and five training bootstraps; its explicit subsequent `conformalize` fits another five bootstrap predictors on calibration rows and replaces that bootstrap bank. The full-training predictor stays unchanged. The native factory therefore makes11 XGBoost estimator fits per horizon, confirmed by the synthetic operation ledger, not six. Its retained calibration bootstrap state and OOB conformity scores are part of the immutable shared owner. NaN OOB scores from rows omitted by no bootstrap are retained/countable; native MAPIE finite-score quantiles remain unchanged. They do not justify dropping scientific test rows.

CQR's native correction uses `numpy.quantile(scores, level*(1+1/n), method='higher')` as implemented by the pinned MAPIE version. Amendment-004 online CQR uses its separately specified exact rank. Native static EnbPI uses MAPIE's score symmetry and corrected quantile convention; updated EnbPI uses signed own-point residuals, causal availability and the frozen amendment-004 ranks. These are identified policies, not interchangeable formulas.
