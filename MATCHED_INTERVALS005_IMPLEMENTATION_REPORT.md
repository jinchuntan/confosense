# Matched intervals005 implementation and verification

The executable `src.matched_intervals005` now provides freeze/readiness/run/validate/resume for the authorized first BDG2 triplet. [The completed pilot report](BDG2_MATCHED_INTERVAL_METHODS_PILOT_REPORT.md) is the empirical result; this adapter is deliberately guarded to the authorized scope.

Immutable fitted/calibrated owner stages, cached raw predictions, DSCP calibrator/assignment chunks and emitted streams have separate content checksums. Ready partial stages survive atomic rename failure. Interrupted uncommitted fits require explicit reconciliation and are not automatically repeated. The durable coordinator retains exact process identity, exclusive lock, actual exit receipts and surviving-worker adoption. A completed resume rejects corrupt artifacts and blocks both learned fitting and calibrator fitting.

[Frozen method specification](smart_building_conformal/protocols/matched_intervals005/bdg2_f2_s42_v1/method_specification.json) records actual classes, parameters, scoring, native quantile conventions, online rank conventions, initialization and crossing handling. The original method specification incorrectly described native CQR as symmetric; [the resolved specification](review/matched_intervals005_bdg2_20260914/method_specification_resolved_v2.json) documents the actual installed asymmetric native convention. Amendment-004 online CQR retains max-score ranks; the existing generic signed-residual CQR wrapper is not used. Raw crossings remain visible and ordered emitted bounds are recorded.

The synthetic evidence contains 20 two-group/two-horizon method streams,34 tiny learned-estimator fits (4 CQR wrappers/12 quantile estimators and 2 EnbPI wrappers/22 XGBoost fits), two DSCP calibrators and one KMeans candidate, separate from real results. The initial 25-check command had one scalar-fixture failure;24 passed. Its corrected no-fit recheck and an additional native-formula/unseen-group test passed, reusing saved owners. Eleven generic coordinator tests passed. A further no-fit held-out-truth perturbation through the joint DSCP assembly also passed; its first reader attempt used the wrong saved outcome column and was corrected without touching owners or scientific code. See [supplemental acceptance](review/matched_intervals005_bdg2_20260914/SUPPLEMENTAL_ACCEPTANCE.md). Eight additional no-fit native-CQR and read-only source-identity regression checks passed after the first validation erratum; those eight plus a new native-EnbPI accumulator check passed after the second correction. The final ten-check no-fit rerun also includes a new exact float32 CSV roundtrip check. The final eleven-check no-fit rerun adds a referenced-global scan after the cleanup import repair. Thus **49 distinct acceptance checks are resolved**; the initial failure is retained in [the recovery record](review/matched_intervals005_bdg2_20260914/SYNTHETIC_RECOVERY.md). No tiny learned or calibrator fit was repeated for recovery.

DSCP uses verified old matched XGBoost owners through a read-only historical loader. The old source/protocol/owner hashes remain explicit even though adding modules changes the new source digest. Each joint role is checked against published memberships and target timestamps. Assignment uses bounded exact per-sequence distances; the first 64 rows are checkpointed and reused. All remaining rows are evaluated, assignments are shared across levels, and serialization checks recompute the full test cohort without calibrator fitting.
